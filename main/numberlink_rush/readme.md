# ナンバーリンク・ラッシュ (タイムアタック)

Pyxel で作ったナンバーリンクのタイムアタックです。5 分間で何問解けるかを競います。

## ブラウザ上での実行
- こちらからプレイできます。[ブラウザで遊ぶ](https://kitao.github.io/pyxel/wasm/launcher/?play=ku-ron.pyxel_minigames.main.numberlink_rush.numberlink_rush_v1_0&gamepad=enabled)

## ルール

- 同じ数字のペアを線で繋ぎます。線は分岐・交差できません。
- **全マスを線で埋め、かつ全ペアを繋ぐ**とクリアです（空きマスや数字に繋がらない線が残っているとクリアになりません）。
- クリアすると自動的に次の問題に進みます。
- 詰まったらスキップできます（回数は別に記録されます）。
- 5 分経つと終了。解けた問題数がスコアです。

## 難易度

| 難易度 | 内容 |
|---|---|
| EASY | 外周に数字あり、数字同士の隣接あり |
| NORMAL | 外周に数字あり、数字同士の隣接なし |
| HARD | 外周に数字なし、数字同士の隣接なし |

問題は 10x10 で、各難易度およそ 100 問（EASY 100・NORMAL 100・HARD 97）を事前に自動生成して同梱しています（すべて唯一解・全マス使用）。
プレイごとにシャッフルして出題するので、順番は毎回変わります。

## 操作方法

### キーボード
| キー | 動作 |
|------|------|
| 矢印キー | カーソルの移動（タイトルでは上下で難易度、左右で BGM を選択） |
| Enter / Space | タイトルで開始、結果画面でタイトルへ |
| Space | 移動モード / 描画モードの切り替え |
| R | 現在の問題をリセット |
| S | 現在の問題をスキップ |
| M | 中断してタイトルへ |
| ESC | ゲーム終了 |

### ゲームパッド
| ボタン | 動作 |
|--------|------|
| 十字キー | カーソルの移動（タイトルでは上下で難易度、左右で BGM を選択） |
| A (下) | 移動モード / 描画モードの切り替え（タイトルでは開始） |
| B (右) | 決定 |
| X (左) | リセット |
| Y (上) | スキップ |
| BACK | 中断してタイトルへ |

カーソルが乗っている数字の両端は点線の枠で点滅して、目標が分かるようになっています。

## BGM

BGM と効果音は MML でコード内に書いてあります（リソースファイルはありません）。
タイトル画面の左右キーで 3 曲（BRIGHT / DORIAN / POP）と OFF を選べ、選んだ曲がその場で試聴できます。
残り 30 秒でテンポが上がり、残り 10 秒は毎秒ティック音が鳴ります。
ゲーム開始時には 3・2・1・START のカウントダウンが入ります。

## ファイル構成

```
src/
├── main.py          … タイトル / 結果画面、アプリ本体
├── rush_game.py     … プレイ画面（カーソル操作、クリア判定、タイマー）
├── board.py         … 盤面と線の管理（ナンバーリンク本編から流用、全マス埋め判定を追加）
├── puzzle_pool.py   … 問題プールの読み込みとシャッフル
├── bgm.py           … MML の BGM / 効果音
├── bgm_archive.py   … 保留中の曲の保管（ゲームでは未使用）
├── data/pool_A.json … 問題プール（EASY）
├── data/pool_B.json … 問題プール（NORMAL）
├── data/pool_C.json … 問題プール（HARD）
└── utils/           … 色・グリッド描画
```

## 実行

```
cd src
python main.py
```
または
```
pyxel play numberlink_rush_v1_0.pyxapp
```

動作確認は Pyxel 2.9.9 で行っています（MML の BGM は Pyxel 2.4 以降の文法。古い Pyxel では自動で旧文法に変換して鳴らします）。

最高スコアは起動中のみ保持されます（ブラウザ版では保存されません）。

## 問題の追加

問題は別リポジトリの生成器（`numberlink_hard_generate.py`）で作り、`build_pool.py` で `data/pool_X.json` にまとめています。
